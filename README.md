# 魂契远征 · Soul Pact

手机竖屏网页游戏：**战棋冒险 × 卡牌构筑 × 灵魂收集 RPG**
（《火焰纹章》的网格战术 + 《杀戮尖塔》的爬塔卡牌 + 《宝可梦》的收集进化）

纯静态网页，无需构建、无需后端，直接用浏览器打开 `index.html`（或用任意静态服务器托管）即可游玩。

## 玩法概览

- **远征**：穿越 3 个区域（迷雾森林 → 沙海遗迹 → 深渊魔城），每区 8 层路线图（节点：战斗、精英、事件、商店、营地、宝藏、灵魂祭坛，最后是区域首领）。**战场随区域变大**：6×7 → 7×8 → 8×9。
- **战棋战斗**：英雄与召唤的灵魂都能 **移动 + 普通攻击 / 技能**。近战 / 远程各有定位，普通攻击会被射程内的敌人 **反击**；地形有林地（受伤-25%）、军旗（占领者每回合+1能量）、泉水、灼烧地面、墙；战场上还有 **宝箱**（走上去占领，或打碎它都能开箱）和会爆炸的 **火药桶**。
- **多种战斗目标**：歼灭、击杀指挥官、占领据点、坚持 N 回合（持续有援军）、击败首领。
- **卡牌（炉石式节奏）**：法力逐回合增长（3→7），每回合抽 2 张，**手牌不弃**；攻击 / 技能 / 能力 / 召唤 / **装备牌**（永久强化单位）/ **战术牌**（筑墙、立旗、换位、调兵）/ 大量 **随机牌**（发现、骰子、抛硬币、随机召唤、随机分配伤害……）。构筑限制：普通/优秀同名最多 2 张，稀有 1 张。
- **灵魂收集**：击败魔物后可尝试收服；重复收服提升星级；灵魂会升级、**进化**（三阶段），并作为「召唤牌」进入牌组。
- **属性克制**：水 > 火 > 木 > 雷 > 水，光 ⇄ 暗互相克制（×1.5 / ×0.75）。
- **内容规模**：117 种魔物、13 个职业、约 245 张卡牌、45 件装备、25 个随机事件、36 种魔物技能。
  职业：骑士、法师、唤灵师、游侠、牧师、刺客、圣骑士、德鲁伊、狂战士、武僧、吟游诗人、炼金术士、机械师。
- **永久成长**：每次远征结算「魂晶」，用于解锁职业与永久强化；图鉴记录所有遇见与收服的灵魂。本地存档，可中途保存继续。

## 运行

```bash
python3 -m http.server 8000
# 手机与电脑在同一网络时，用手机浏览器打开 http://<电脑IP>:8000
```

也可以直接部署到 GitHub Pages / Netlify / 任何静态托管，并可「添加到主屏幕」像 App 一样全屏游玩。

URL 参数 `?fast=1` 关闭动画等待（用于自动化测试）。

## 代码结构

| 文件 | 说明 |
| --- | --- |
| `js/data.js` | 元素、角色定位、技能库、魔物家族与物种表（117 种） |
| `js/cards.js` | 卡牌库、职业、卡牌升级与自动生成描述 |
| `js/items.js` | 装备与随机事件 |
| `js/battle.js` | 战斗引擎：回合、效果解释器、移动、AI |
| `js/game.js` | 存档、地图生成、遭遇生成、收服与奖励 |
| `js/battleui.js` | 战斗界面（棋盘、手牌、交互、特效） |
| `js/ui.js` | 其他界面与流程（标题、选职业、地图、商店、事件、图鉴…） |

新增内容都是数据驱动：往 `FAM`（魔物家族）、`C(...)`（卡牌）、`GEAR_RAW`（装备）、`EVENTS`（事件）里加一行即可。
