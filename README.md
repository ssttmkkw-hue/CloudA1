# 魂契远征 · Soul Pact

手机竖屏网页游戏：**战棋冒险 × 卡牌构筑 × 灵魂收集 RPG**
（《火焰纹章》的网格战术 + 《杀戮尖塔》的爬塔卡牌 + 《宝可梦》的收集进化）

纯静态网页，无需构建、无需后端，直接用浏览器打开 `index.html`（或用任意静态服务器托管）即可游玩。

## 玩法概览

- **远征**：穿越 3 个区域（迷雾森林 → 沙海遗迹 → 深渊魔城），每区 8 层路线图，节点包括战斗、精英、事件、商店、营地、宝藏、灵魂祭坛，最后挑战区域首领。
- **战棋战斗**：6×7 网格。英雄与召唤出的灵魂都能 **移动 + 攻击/技能**，有障碍、陷阱、灼烧地面、治愈泉；可开启「危险区」预览敌人下一回合的攻击范围。
- **卡牌**：每回合抽 5 张、3 点能量。攻击 / 技能 / 能力 / 召唤，123 张卡牌（含诅咒），每张可在营地升级。
- **灵魂收集**：击败魔物后可尝试收服。标记、水晶💎、职业与装备都会影响成功率；重复收服提升星级。灵魂会升级、**进化**（三阶段），并作为「召唤牌」进入牌组。
- **属性克制**：水 > 火 > 木 > 雷 > 水，光 ⇄ 暗互相克制（×1.5 / ×0.75）。
- **内容规模**：117 种魔物（36 个家族 × 3 阶段 + 3 位首领 + 6 位传说元素之灵）、6 个职业、45 件装备、25 个随机事件、36 种魔物技能。
- **永久成长**：每次远征结算「魂晶」，用于解锁职业与永久强化；图鉴记录所有遇见与收服的灵魂。
- 本地存档（`localStorage`），支持中途保存并继续。

## 运行

```bash
python3 -m http.server 8000
# 手机与电脑在同一网络时，用手机浏览器打开 http://<电脑IP>:8000
```

也可以直接部署到 GitHub Pages / Netlify / 任何静态托管，并可「添加到主屏幕」像 App 一样全屏游玩。

URL 参数 `?fast=1` 关闭动画等待（用于自动化测试）。

## 代码结构

| 文件 | 说明 |
| --- | --- |
| `js/data.js` | 元素、角色定位、技能库、魔物家族与物种表（117 种） |
| `js/cards.js` | 卡牌库、职业、卡牌升级与自动生成描述 |
| `js/items.js` | 装备与随机事件 |
| `js/battle.js` | 战斗引擎：回合、效果解释器、移动、AI |
| `js/game.js` | 存档、地图生成、遭遇生成、收服与奖励 |
| `js/battleui.js` | 战斗界面（棋盘、手牌、交互、特效） |
| `js/ui.js` | 其他界面与流程（标题、选职业、地图、商店、事件、图鉴…） |

新增内容都是数据驱动：往 `FAM`（魔物家族）、`C(...)`（卡牌）、`GEAR_RAW`（装备）、`EVENTS`（事件）里加一行即可。
